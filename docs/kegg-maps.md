# KEGG pathway maps for the panel genes

Each link opens the human (hsa) KEGG map with our 14 panel genes coloured orange. All 14 genes are passed in every link; genes not on a map are simply ignored.
Gene membership checked with the KEGG REST API on 16 Oct 2026 (rest.kegg.jp/link/pathway/...). KEGG is copyrighted by Kanehisa Laboratories; academic users may use the website freely. For slides or a public GitHub portfolio, link to the maps and cite KEGG rather than pasting map images.
